# akpw Homebrew Tap

This is a custom Homebrew tap for hosting various tools, scripts, and packages outside of the official `homebrew-core` repository.

## Available Formulae

### `reny`
A lightweight, fast, and safe batch renaming and filesystem organization tool

## How do I install these formulae?

First, you need to tap this repository into your local Homebrew installation:

```bash
brew tap akpw/tap
```

Once the tap is installed, you can install any formula in this repository just like a normal Homebrew package:

```bash
brew install reny
```

Or, if you prefer to do it in one command:

```bash
brew install akpw/tap/reny
```
